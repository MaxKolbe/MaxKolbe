# MAXMILLIAN

**AI Backend Engineer** · Building reliable backend systems and AI-powered applications

> I am a Backend Engineer obsessed with building backend systems that don't break in production.
>
> My experience includes building REST APIs and backend systems for enterprise applications featuring role-based authentication, custom applicant data-collection workflows, automated notification systems, OTP authentication, and AI-powered functionality. Recently, I have been pushing AI further into my backend work by building RAG pipelines, working with embeddings, MCP, and exploring what makes AI features reliable and production-ready.
>
> I enjoy understanding why systems work the way they do.
